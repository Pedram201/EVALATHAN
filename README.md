<h1 align="center">E V A L A T H A N</h1>

The one-stop evaluation platform for software, languages, compilers, and engines (and of course agentics, in good time.

Evalathan grades a product across its life cycle. One conductor, Hydra, opens only the engines whose evidence exists, and the report shows the blanks.

**v0.2** is a local runner. It does not award a state-of-the-art stamp. A deferred cell is not a fail and not a zero.

```bash
pip install -e ".[dev]"
evalathan scan path\to\tree
evalathan scan path\to\tree --json report.json
```

## What v0.2 runs

Sixteen engines always appear. Hydra is the conductor and is not a seventeenth score. Point the scan at the tree you want graded. A record that lives in another repository is read when that repository is the path you pass.

| Engine | What it runs |
|--------|----------------|
| Devly | Commit count when git history exists. No SFIA (Skills Framework for the Information Age) level. |
| Archly | Notices a README or a prior Evalev file. Does not re-score the 97 principles. |
| Codely | Counts Python branch nodes. Other language packs are named and left unrun. An unknown language is not a pass. |
| Refactorly | Identical file bytes, unreferenced Python names, and git churn. |
| Mixly | File share by language. A rewrite stays with the maintainer. |
| Runly | A 200000-step microbench on Python trees, plus SPEC, LLVM test-suite, or pyperformance files when those files are present. |
| Levi | A 4Uvals (Ultimate User-User-User evaluations) JSON record with a gate. ISO/IEC 42001 is not the sitting grade. |
| Menschly | A timer in source, including an optional FUSS (For-User Session Switch) file. README wording alone stays provisional. |
| Tokly | A sealed before/after or TOKEX (Token Expenditure) pair. Savings are max(0, before - after). |
| Pressly | SSIM, VMAF, or byte-size numbers printed in a log. |
| Triadly | A declared M3 order (cost, speed, impact). |
| Chorely | An agent roster. SASPIANT (Specific and Specialized, Pain-In-the-Ass, Non-critical Tasks) counts rows. |
| Trajectly | Saved trace steps in the tree. |
| Warrantly | Claims that carry a source, recipe, or evidence field. |
| Domly | A versioned question bank, and answers when a second file is present. |
| Stackly | The vector after the other stations run. It does not blend them into one float. |

Menschly accepts any real stop. FUSS (For-User Session Switch) is an optional timer, not a required plugin and not the only way to pass. Naming FUSS in a README is not itself a stop.
