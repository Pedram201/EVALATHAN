EVALATHAN

The one-stop evaluation platform for software, languages, compilers, and engines.

Evalathan is one evaluation harness. Hydra is the conductor. It calls sixteen evaluators, short name evalers. Each evaler reports against a life-cycle gate. A blank stays a blank. It is not a fail and it is not a zero.

Install

You need Python 3.10 or newer. The Windows release (10 or 11) and the Mac release do not matter beyond that. Evalathan is not on the public Python package index yet. Install it from the GitHub repository.

Windows

py -m pip install "evalathan @ git+https://github.com/Pedram201/EVALATHAN.git"
evalathan scan C:\path\to\tree

Mac

python3 -m pip install "evalathan @ git+https://github.com/Pedram201/EVALATHAN.git"
evalathan scan ~/path/to/tree

Add --json report.json to write the same result to a file. The grade stays on your machine.
